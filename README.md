# Readcomic

Читалка комиксов для Android с реалистичным перелистыванием страниц: лист изгибается
по цилиндру, тянется за пальцем, отбрасывает мягкую тень, а на обороте видна бумага
с лёгким просвечиванием печати.

## Возможности

- **Перелистывание «как в жизни»** (OpenGL ES 3.0):
  - потяни край страницы — лист идёт за пальцем, отпусти — долистнётся или упадёт обратно;
  - потяни за уголок — загибается именно уголок, ближе к корешку сгиб выпрямляется;
  - быстрый взмах листает даже после короткого движения;
  - падающий лист можно поймать пальцем;
  - тап по правой/левой трети экрана — анимированное перелистывание «с подхватом уголка»;
  - кнопки громкости тоже листают;
  - мягкая тень от листа, блик на изгибе глянцевой бумаги, тень у корешка, лёгкая перспектива;
  - сбоку виден торец стопки оставшихся страниц (толщина зависит от их количества);
  - на последней странице лист только приподнимается и падает обратно.
- **Удобное чтение**: щипок и двойной тап для увеличения (страница при этом подгружается в
  повышенном разрешении), перетаскивание с инерцией, полноэкранный режим, экран не гаснет.
- **Меню** (тап по центру): номер страницы, ползунок быстрого перехода, цвет фона.
- **Библиотека**: обложки, прогресс чтения, место остановки запоминается.
- **Форматы**: CBZ/ZIP, CBR/RAR (включая RAR5), CB7/7z, CBT/TAR — через
  [libarchive](https://github.com/zhanghai/AndroidLibArchive); PDF — через `PdfRenderer`.
  Формат определяется по содержимому файла, а не по расширению.
- Открытие файлов из файловых менеджеров («Открыть с помощью»).
- Встроенный демо-комикс, который рассказывает, как всем пользоваться.

## Сборка

Нужны JDK 17+ и Android SDK (compileSdk 37).

```bash
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest    # юнит-тесты геометрии загиба и логики перелистывания
```

Или просто открыть проект в Android Studio и нажать Run.

Минимальная версия Android — 8.0 (API 26), нужен OpenGL ES 3.0.

## Как устроено

```
app/src/main/
├── assets/shaders/           GLSL ES 3.00
│   ├── curl_common.glsl      деформация листа: плоская часть → цилиндр → перевёрнутая часть
│   ├── page.vert / page.frag страница: свет, блик, оборот, приём тени
│   ├── shadow.vert/.frag     проекция поднятого листа на стол вдоль света
│   ├── blur.frag             размытие тени (полутень)
│   └── background.frag       стол, тень комикса, торец стопки
└── java/com/readcomic/
    ├── curl/
    │   ├── CurlMath.kt              геометрия сгиба (линия сгиба, радиус, наклон, «корешок не отрывается»)
    │   ├── PageTurnController.kt    состояние: текущая страница, пружина, жесты, зум (без OpenGL, покрыт тестами)
    │   ├── Spring2D (Spring.kt)     критически задемпфированная пружина
    │   ├── CurlRenderer.kt          отрисовка: тень в текстуру → размытие → стол → страницы
    │   ├── PageTextureCache.kt      фоновое декодирование страниц и загрузка текстур
    │   └── PageCurlView.kt          GLSurfaceView + обработка касаний
    ├── data/                        чтение архивов/PDF, демо-комикс, библиотека (JSON)
    └── ui/                          экраны на Jetpack Compose
```

Лист — сетка 64×96, изгибаемая в вершинном шейдере вокруг цилиндра (подход как у
[harism/android-pagecurl](https://github.com/harism/android-pagecurl), но с наклоном
сгиба, перспективой и тенями через offscreen-проход). Точка листа, за которую взялись,
оказывается ровно под пальцем; радиус изгиба растёт с длиной протяжки, чтобы край
приподнимался сразу и лист не выглядел трубкой.
